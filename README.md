# 🎵 Music Bot for Telegram

Telegram uchun kuchli musiqa boti. YouTube, SoundCloud, Deezer, Instagram, TikTok, Snapchat, Pinterest va Likee’dan audio/video yuklab oladi.

## ✨ Xususiyatlar

- 🎧 Qo‘shiq nomi yoki artist bo‘yicha qidiruv (SoundCloud + YouTube Music + Deezer)
- 🔗 Link yuborish: YouTube, Instagram, TikTok, Snapchat, Pinterest, Likee
- 🎬 Videodan audio chiqarish
- 📥 Videoni yuklab olish (720p gacha)
- ❤️ Sevimlilar ro‘yxati
- 📜 Yuklash tarixi
- 🏆 TOP 10 eng ko‘p yuklangan qo‘shiqlar
- ⚙️ Sozlamalar (natijalar soni 5/10)
- 👑 Admin panel (statistika, foydalanuvchilar ro‘yxati)
- ⏱ Yuklab olish chegarasi (semafor – 3 tagacha parallel)
- 🗜 50MB dan katta fayllarni avtomatik siqish (ffmpeg)
- 🏷 MP3 fayllarga metadata (ID3 tag) qo‘shish

## 🚀 O‘rnatish

### 1. Talablar

- Python 3.9+
- ffmpeg (tizimda o‘rnatilgan)
- Telegram Bot Token ([@BotFather](https://t.me/BotFather) dan oling)

### 2. Klonlash va o‘rnatish

git clone https://github.com/yourusername/music-bot.git
